# Roadmap

## v0.1 — Fundação

- [x] comunicador visual;
- [x] faixa de frase + síntese de voz;
- [x] letras e números;
- [x] Agora/Depois;
- [x] área do adulto;
- [x] cartões com fotos locais;
- [x] histórico local sem score;
- [x] PWA/offline;
- [x] privacidade local-first.

## v0.2 — Personalização de comunicação

- [ ] editar e reordenar cartões manualmente sem reorganização automática;
- [ ] ocultar/restaurar cartões sem apagar;
- [ ] múltiplos quadros personalizados por contexto (refeição, parque, banho, carro);
- [ ] gravar voz familiar opcionalmente, mantendo áudio local;
- [ ] exportar/importar configuração criptografada para backup;
- [ ] impressão de quadro de comunicação em PDF.

## v0.3 — Interação e linguagem

- [ ] páginas de cenas visuais com hotspots configuráveis;
- [ ] modo de leitura compartilhada;
- [ ] verbos e descritores adicionais;
- [ ] busca de palavra na área do adulto;
- [ ] modelagem guiada para cuidadores sem transformar em teste.

## v0.4 — Colaboração profissional opcional

Somente depois de definir privacidade, consentimento, threat model e requisitos legais:

- [ ] exportar resumo legível para fono/terapeuta;
- [ ] perfis de configuração prescritos/importáveis;
- [ ] sincronização familiar opt-in com criptografia;
- [ ] nenhuma telemetria de criança por padrão.

## Fora de escopo deliberadamente

- diagnóstico de autismo;
- “nível” ou score de autismo;
- reconhecimento automático de fala para dizer “certo/errado”;
- ranking, streak, moedas ou recompensa aleatória;
- anúncios;
- feed infinito;
- chatbot aberto para a criança;
- substituição de acompanhamento clínico.
